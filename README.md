# travelers-guide

the travelers guide welcome center: a portal to one-page navigators for machines with hidden depths.

- [hermod-navigator](https://mellotom.github.io/hermod-navigator/): travelers guide for talking to machines (squarp hermod+)
- [lubadh-navigator](https://mellotom.github.io/lubadh-navigator/): travelers guide for navigating time loops (instruo lúbadh)
- [morphagene-navigator](https://mellotom.github.io/morphagene-navigator/): travelers guide for navigating wormholes (make noise morphagene)

live page: https://mellotom.github.io/travelers-guide/

design homage to the [house of x / powers of x](https://www.marvel.com/comics/guides/1556/house-of-xpowers-of-x) data pages by tom muller with jonathan hickman. not affiliated with squarp, instruo, make noise or marvel.
